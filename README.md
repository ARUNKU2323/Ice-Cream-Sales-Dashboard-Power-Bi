🍦 Ice Cream Sales Dashboard – Power BI Project

📊 Project Overview

This Power BI project visualizes and analyzes ice cream sales data to uncover key insights about product performance, sales trends, and customer preferences. The dashboard helps businesses make data-driven decisions on product strategy, pricing, and seasonal demand.

🧠 About Power BI

Microsoft Power BI is a powerful business intelligence tool used for:

Connecting to various data sources (Excel, SQL, web, etc.)

Transforming raw data into clean, structured datasets

Creating interactive dashboards and reports

Visualizing insights through charts, KPIs, and slicers

Enabling real-time data analysis and sharing through Power BI Service

In this project, Power BI is used to:

Import and clean the ice cream dataset

Build visual reports for monthly and product-level performance

Use filters and slicers for deeper analysis

📁 Dataset Description – icecream_dataset_cleaned.xlsx

This Excel file is the cleaned dataset used as the data source for the Power BI dashboard.
It contains processed and structured data ready for visualization.

Key Columns (example structure):

Column Name	Description

Date	Date of sale transaction
Flavor	Ice cream flavor sold (e.g., Chocolate, Vanilla, Strawberry)
Quantity	Number of ice cream units sold
Revenue	Total revenue generated from sales
Region	Geographic location or branch of sale
Temperature	Average temperature on the sale date (used for demand correlation)
Customer_Type	Customer category (e.g., Regular, New, Walk-in)

📊 Power BI Dashboard Features

The Power BI dashboard built using this dataset includes:

Sales Overview: Total and average sales by year, month, and region

Top Models: Performance of different vehicle models

Trend Analysis: Monthly and yearly growth visualization

Geographic Insights: Regional breakdown of sales (if applicable)

KPIs: Dynamic cards for total revenue, total units sold, and year-over-year growth
